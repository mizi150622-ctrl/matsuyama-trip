# 엄마랑, 마쓰야마

2026년 12월 3일–6일, 3박 4일 여행 안내 사이트입니다.

큰 글씨, 날짜별 일정, 식당·숙소 지도 링크, 글씨 확대와 공유 기능을 제공합니다.

GitHub Pages: https://mizi150622-ctrl.github.io/matsuyama-trip/

## 게시 방식

- 공개 사이트는 `gh-pages` 브랜치의 루트(`/`)에서 게시됩니다.
- 별도 패키지 설치나 빌드 없이 HTML, CSS, JavaScript를 그대로 제공합니다.
- 사이트 수정 시 `main`에서 검증한 뒤, `gh-pages`도 같은 커밋으로 fast-forward하여 게시합니다.
- 배포 상태는 GitHub 저장소의 Actions → `pages build and deployment`에서 확인합니다.

일정은 추천안이며 항공편·예약에 따라 변경됩니다.
사진 출처는 assets/sources.json과 사이트 하단에서 확인할 수 있습니다. 사진 저작권은 각 원권리자에게 있습니다.
